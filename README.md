### About me

Final-year **Computer Science** student at Universidad del Valle, building production systems at the intersection of **backend engineering**, **AI agent architecture**, and **cybersecurity**.

I've shipped multi-tenant SaaS platforms with full data isolation, RAG pipelines with Gemini + Qdrant, idempotent transaction systems, and orchestrated LLM agents across GPT-4, Grok, and Gemini. My security focus covers cryptography, access control models (MAC, DAC, RBAC, ABAC), audit logging, and non-repudiation.

I take full ownership of delivery — from architecture decisions and database design to CI/CD pipelines and frontend when needed.
